# Agent guidelines

The guidelines for this application live in **`CLAUDE.md`** in this same
directory. Read that file before making changes — it is generated by Laravel
Boost and covers Laravel, PHP, Filament, Pint and testing conventions for this
specific app.

This file is a pointer rather than a copy, so the two can never disagree.

## Why this file is not generated

Laravel Boost is installed here, but `php artisan boost:install` was run inside
the app container, and Boost detects agents by looking for their CLI or config
on the machine it runs on. Inside the container only Claude Code was found, so
Boost wrote `CLAUDE.md` and left this file alone.

If you work with another agent (Codex, Cursor, Copilot, Zed, …), re-run
`php artisan boost:install --guidelines` from a machine where that agent's CLI
is installed. Boost will then replace this whole block with real guidelines.

## One thing to know before running anything

There is no PHP on the Windows host — the entire stack runs in Docker. Artisan,
Composer and the test suite are run through the container:

```sh
docker exec knalpot-app php artisan test
docker exec knalpot-app composer install
```

See `README.md` for ports, credentials and the rest of the setup.
